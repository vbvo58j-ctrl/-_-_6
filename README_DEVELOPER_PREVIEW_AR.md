# المعاينة التجريبية للمطور

أضيف خيار «محادثة وهمية تجريبية (للمطور)» داخل الإعدادات. يفتح شاشة محادثة محلية تحتوي على رسائل نموذجية، وتسمح بإضافة رسائل تجريبية من حقل الكتابة. لا تستخدم هذه الشاشة اتصال Bluetooth أو Wi-Fi ولا تحفظ الرسائل في محادثات المستخدمين ولا ترسلها لأي شخص. زر المرفقات يعرض تنبيهًا بأن المرفقات غير مفعلة في وضع المعاينة.

لم يتم بناء APK أو تشغيل اختبارات Flutter في بيئة العمل، لذا يُرجى اختبار المشروع باستخدام Flutter قبل النشر.
